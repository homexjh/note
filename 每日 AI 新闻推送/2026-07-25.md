## 一、大模型发展

### 1. Anthropic 发布 Claude Opus 5：半价逼近 Fable 5，"性价比旗舰"登场
**事件内容**：7 月 25 日凌晨，Anthropic 正式发布 Claude Opus 5，全平台上线（Claude / Claude Code / API / Bedrock / Google Cloud / Microsoft Foundry）。定价维持 Opus 4.8 水平——输入 $5 / 百万 token、输出 $25 / 百万 token，仅为旗舰 Fable 5 的一半。核心亮点包括：可调节的"Effort（思考档位）"；ARC-AGI 3 得分 30.2%（GPT-5.6 Sol 仅 7.8%）；Frontier-Bench v0.1、CursorBench 3.2（最高档距 Fable 5 峰值差 0.5%）、Zapier AutomationBench 等多项登顶；具备主动自我校验与迭代能力；安全性为 Anthropic 迄今最高（失准行为得分 2.3）。
**值得关注的原因**：在国产开源/闭源模型"爆更"压力下，海外大厂首次明确转向"性价比"路线——用一半价格提供准顶配能力。这标志模型竞争主轴从"参数/跑分"切换为"单位成本下的有效智能"，对企业级 Agent 落地尤为关键。

### 2. Meta Llama 4 开放权重正式发布，移除商业限制
**事件内容**：7 月 25 日 UTC 00:00，Meta 发布 Llama 4 开放权重，覆盖 7B / 13B / 34B / 70B 四档，采用新 Llama License 3.0——**首次移除"禁止开发竞争产品"条款**，允许在金融、医疗、法律等受监管行业合法微调商用。架构上引入 Dynamic KV Cache Compression，同等上下文显存占用较 Llama 3-70B 降 37%，单张 H100（80GB）即可跑 128K 上下文。
**值得关注的原因**：这是开源生态的里程碑式解锁，直接打通了 open-weight 模型在垂直行业的商业化路径，也将倒逼其他闭源厂商重新评估开放策略。

### 3. 25 家机构联署公开信呼吁"勿过早限制开放权重 AI"
**事件内容**：7 月 24 日，英伟达、微软、Meta、IBM、戴尔、Palantir、Hugging Face 等 25 家美国企业与机构联合发表《开放权重与美国在人工智能领域的领导力》公开信，呼吁政策制定者避免对 open-weight 模型实施"一刀切"限制，主张以精准法律/商业框架处理非法蒸馏问题。黄仁勋以首条 X 帖转发，纳德拉力挺，马斯克表示"完全支持"。值得注意的是，**OpenAI 与 Anthropic 均未署名**，但奥特曼表态"乐见"并希望美国在开源与专有两条线都胜出。
**值得关注的原因**：公开信的直接导火索是中国开源模型（Kimi K3 等）的快速崛起引发美方管制讨论。它把"开源 vs 闭源"的路线之争摆上台面，也预示着全球 AI 治理正围绕"开放权重"重新划线。

### 4. OpenAI 上线 ChatGPT Health，同步陷入医疗误导诉讼
**事件内容**：7 月 24 日，OpenAI 向美国 18 岁以上用户开放 ChatGPT Health，可接入 Apple Health 与部分医疗机构记录，GPT-5.6 Sol 在医疗问答准确性上据称超医生。几乎同时，一名佛罗里达牧师起诉 OpenAI，指其长期错误医疗建议延误治疗并导致致命肺栓塞，要求暂停该功能并加强风控。OpenAI 重申产品"不用于医学诊断"、健康数据不用于训练。
