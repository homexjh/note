## 一、大模型发展

### 1. DeepSeek-V4 Preview 正式上线并同步开源，1M 上下文成全系标配
**事件内容：** DeepSeek 发布 V4 预览版并开源权重。双版本布局——V4-Pro（总参数 1.6T、激活 49B，对标顶级闭源）与 V4-Flash（284B、激活 13B，主打性价比）。技术核心是 **DSA（DeepSeek Sparse Attention）稀疏注意力 + token 维度压缩**，把百万 token 长上下文的算力/显存开销大幅压低，使 1M 上下文成为所有官方服务的默认配置。模型针对 Claude Code、OpenClaw、OpenCode、CodeBuddy 等主流 Agent 做了专项适配，支持 OpenAI / Anthropic 双 API 与思考/非思考双模式。
**值得关注的原因：** 继 Kimi K3 之后，国产开源模型再次把「长上下文 + Agent 能力 + 极致性价比」三件套推向台前。DSA 机制让百万上下文从「闭源王牌」变成「水电煤」级普惠能力，直接冲击依赖长上下文收费的商业 API，也进一步巩固开源生态对闭源的替代逻辑。

### 2. 微软发布 Mage-VL：4B 编码原生流式多模态基础模型
**事件内容：** 微软推出 Mage-VL，一个仅 4B 参数的编码原生（code-native）流式多模态基础模型。视觉编码器从零训练，借鉴视频编解码器的 I/P 帧机制，将视觉 token 数量压缩超 75%，在保持准确率持平的前提下推理速度最高提升 3.5 倍。同日微软披露已推出内部 AI 模型，部分场景成本最高降低 89%。
**值得关注的原因：** 「小参数 + 高压缩 + 流式」正成为端侧/边缘多模态的新范式。75% 的视觉 token 压缩意味着多模态 Agent 在客户端实时运行的门槛大幅降低，对端侧 AI 与实时视觉理解应用是直接利好。

### 3. Google 三连发：Gemini 蒸馏服务 GA、Interactions API GA、Managed Agents API 加 hooks
**事件内容：** Google 将 **Gemini Distillation Service** 正式 GA，面向企业把大模型蒸馏成小型任务专用版本；**Gemini Interactions API** 改用标准 REST + SSE 替代原 RPC 交互并推 GA；**Managed Agents API** 新增 environment hooks，可在沙箱内阻断 / lint / 审计工具调用，并加入 Gemini 3.6 Flash 作为可选模型与免费层。
**值得关注的原因：** 蒸馏 + 交互 + 可审计 Agent 三件套，显示大厂正从「卖模型」转向「卖模型工厂 + 可控运行时」。environment hooks 是 Agent 安全治理的关键基础设施，呼应了近期自主 Agent 失控事件对行业的警示。

### 4. NVIDIA 发布 Cosmos 3 Edge：4B 端侧世界模型，Jetson Thor 上 15Hz 实时推理
**事件内容：** NVIDIA 在 Hugging Face 发布 Cosmos 3 Edge，一个 4B 参数的端侧世界模型，专为机器人设计，可在 Jetson Thor 上以 15Hz 实时推理并生成 32 个机器人动作。Cosmos 系列 HF 下载量已突破 1000 万次。
**值得关注的原因：** 世界模型正式下探到「端侧 + 机器人专用 + 实时」量级，意味着具身智能的「大脑」可以脱离云端独立运行，是机器人走向低成本、低时延、可大规模部署的关键一步。

### 5. OpenAI 发布 whisper-5 / whisper-5-turbo 新一代转录模型
**事件内容：** OpenAI 推出 whisper-5 与 whisper-5-turbo，架构从纯 encoder-decoder 转向「Streaming Hybrid Attention（SHA）」。30 秒音频块延迟低于 200ms（较 whisper-4 降 60%）；原生支持最多 8 人说话人分离，内置声学事件检测（如关门声、电话铃）。turbo 版模型体积压缩 90% 仍保持 98% 准确率，$0.002/分钟可端侧部署。
**值得关注的原因：** 实时语音 AI 的延迟与成本瓶颈被突破，且「声学事件检测」让转录从「听到了什么话」升级到「房间里发生了什么」，对会议、安防、医疗监护、客服质检等场景是直接赋能，也利好无网环境的端侧语音应用。

### 6. Kimi K3 开源持续发酵：人民日报专题解读 + 华为昇腾 0day 全链路适配
**事件内容：** 月之暗面 7/27 开源 Kimi K3（2.8T 参数全球最大开源模型）后，7/29 人民日报刊发《如何炼成全球参数最大开源模型》专题，拆解其 KDA 混合线性注意力、注意力残差技术；同时确认华为昇腾已 0day 全链路适配 K3（H200 / 昇腾 / AMD 三路同通）。月之暗面同步开源训练基建 MoonEP、FlashKDA、AgentEnv，构建「模型 + Infra + 开发者生态」的护城河。
**值得关注的原因：** 开源从「给熟菜」走向「连灶台菜谱一起捐」，Infra 层代码（专家并行通信、注意力内核）此前是大厂压箱底手艺。加上国产算力 0day 适配，国产全栈闭环（模型—框架—芯片）进一步夯实。

### 7. xAI 推 Grok Build 编码代理与「Build」模型，主打开源与 Plan-Execute-Verify
**事件内容：** xAI 将终端编码代理 Grok Build 以 Apache 2.0 开源（GitHub 上线即获 7.7k Star），支持最多 8 个并行子代理、Plan Mode 评审—批准链路、AGENTS.md / MCP 兼容、可热插拔多模型后端。同期披露面向企业 Agent 的「Build」变体模型，原生支持 Plan-Execute-Verify 循环，xAI 称 SWE-bench 较 Grok-3 提升 40%。
**值得关注的原因：** xAI 明确把未来押在「自主执行」而非「聊天」，直接对标 OpenAI Assistants API 与 Google Vertex Agent Builder。Plan-Execute-**Verify** 中的「校验」步骤是对近期 Agent 可靠性危机的架构级回应——CISO 真正要问的是「它在哪个沙箱跑、怎么拔插头」。

### 10. Meta 研究：给主 Agent 配独立记忆模型，治「行为状态衰减」
**事件内容：** Meta 在《Remember When It Matters》中提出「行为状态衰减（behavioral state decay）」概念——信息未丢失却逐渐失去对行动的约束。方案是在主 Agent 旁设独立记忆模型维护执行状态。实验显示该架构使 Claude Sonnet 4.5 在 Terminal-Bench 2.0 的 pass@1 从 37.6% 提升至 45.9%，代码已开源。
**值得关注的原因：** 直指长程 Agent 任务「做了又忘」「把关键函数注释掉」等真实痛点。记忆模型独立化可能成为复杂 Agent 系统的标准架构组件，对长任务可靠性的提升有普适价值。
