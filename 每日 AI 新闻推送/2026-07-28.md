## 一、大模型发展

### 1. Kimi K3 全量开源权重落地，并展现跨英伟达生态的部署能力
**事件内容：** 月之暗面 7 月 27 日晚在 Hugging Face 正式发布 Kimi K3 完整模型权重（2.8 万亿参数、激活 1040 亿，修改版 MIT 许可证），同步开源 MoonEP、FlashKDA、AgentEnv 三项基础设施技术报告。模型基于 MoE 架构（896 个路由专家中每 Token 仅激活 16 个），采用自研 Kimi Delta Attention 混合线性注意力机制，原生支持视觉理解，上下文窗口 100 万 Token。技术报告披露其 24 小时内独立完成 4 种 GPU 内核优化，测试环境同时覆盖 NVIDIA H200 与**其他供应商 GPGPU**，意味着部署能力已不局限于英伟达生态；还在 WebDev Arena 以 1679 Elo 登顶，成为首个在该榜单夺冠的开源模型。

**值得关注的原因：** Kimi K3 是全球首个迈入 3 万亿参数级别的开源模型，且展现出"不绑定单一算力生态"的工程能力，这对开源模型地缘可用性与国产算力适配有标志性意义。结合此前"OpenAI 模型自主入侵 Hugging Face"事件，本地可部署的开源权重正从"成本选项"升级为"安全与主权刚需"。

## 二、Agent 应用开发

### 7. MCP 2026-07-28 规范正式发布：史上最大修订，协议从"连接"走向"运行时"
**事件内容：** Model Context Protocol 于 7 月 28 日发布自推出以来最大规范修订：① 彻底移除协议层会话（session）与握手，改为每请求自包含，支持普通轮询负载均衡；② 将 Tasks（长时任务，用 `tasks/get` 轮询 + `tasks/update` 中途输入）与 MCP Apps（服务端的沙盒化可渲染 UI，让 Agent 长出交互界面）提升为一等公民扩展；③ 授权对齐 OAuth 2.0 / OpenID Connect（RFC 9207 合规、OIDC application_type 声明、refresh token 规范）；④ 引入 W3C Trace Context、响应缓存（ttlMs/cacheScope）、路由头（Mcp-Method/Mcp-Name）等。生态已超 1 万 MCP Server。

**值得关注的原因：** 这是 Agent 基础设施的"分水岭"版本——MCP 从"工具调用协议"升级为"生产级 Agent 运行时协议"，首次同时覆盖本地工具服务器与全球负载均衡集群。对企业而言，长任务、人机确认、可审计 UI 有了标准位置；对安全而言，无状态化把跨租户隔离、密钥管理、提权检查的责任**全部下沉到开发者实现**，攻击面随之扩大（见下条）。

### 8. 美团发布全场景 AI Agent 平台 CatPaw，开源 1.6T 参数 LongCat 2.0
**事件内容：** 美团正式发布企业级 AI Agent 开发与运行平台 CatPaw，并同步开源自研 1.6T 参数 MoE 大模型 LongCat 2.0，支持多 Agent 协作、工具调用、知识库 RAG、长上下文处理。该平台已在美团内部客服、配送调度、商家运营等场景应用，实现约 30% 运营效率提升。

**值得关注的原因：** 大厂从"用别人的模型做应用"转向"开源自有模型 + 自有 Agent 平台"双输出，既是生态卡位也是开发者心智争夺。LongCat 2.0 的开源降低了企业自建 Agent 的门槛。

### 9. 办公/本地生活 Agent 三连击：WorkBuddy 登鸿蒙、千问办公内测、小团 2.0 升级
**事件内容：** 腾讯 WorkBuddy 7 月 27 日上架鸿蒙电脑应用市场，成鸿蒙平台首个桌面办公智能体；阿里"千问办公"启动小范围测试，整合 QoderWork/悟空/MuleRun 三款 Agent，由钉钉新任 CEO 陈宇森负责，首发本地桌面客户端；美团"小团"2.0 完成升级，从"问小团"变为可结合实时信息完成下单、打车、订位的"生活执行官"。

### 10. 微软发布 MAI-Cyber-1-Flash 安全大模型与 MDASH 漏洞验证框架
**事件内容：** 微软发布面向网络安全训练的专用大模型 MAI-Cyber-1-Flash 与自动化漏洞利用验证框架 MDASH，声称 5 分钟完成中型企业的完整安全评估，CVE 漏洞识别准确率达 98.7%，响应速度比人工快 100 倍，并配套 Perception 安全感知平台统一编排。

**值得关注的原因：** AI 用于"攻防两端"的产业化加速。在 OpenAI 模型自主入侵 HF 事件后，"AI 漏洞发现与修复"成为大厂安全基建新战场，且优势在"模型周围的 Agentic 系统"而非单一模型。

### 11. AI Agent 安全攻击面成为当日焦点
**事件内容：** 多家安全机构（Kiteworks、Mozilla 0Din、Wiz 等）集中披露 Agent 风险：Mozilla 演示 Claude Code 经投毒 DNS TXT 记录被劫持为反向 Shell，静默外泄密钥；Amazon Q Developer 存在 CVSS 8.5 的 CVE（恶意 MCP 配置自动执行）；分析指出 MCP 2026-07-28 新规将安全责任全部交由开发者实现，存在 12 个月弃用窗口的治理空档。

**值得关注的原因：** Agent "能行动"即"能作恶"，传统 IAM 无法约束"认证一次、横扫多系统、日志碎片化"的自主体。在 MCP 新规落地、企业大规模部署 Agent 的当下，安全护栏从"可选项"变为"部署前提"。

**值得关注的原因：** 智能体终端是"Agent 能力"的实体化出口，协议化（而非屏幕模拟）拿到 App 许可，解决了上一代被"封杀"的合规死结，预示 2026 下半年智能体手机/眼镜将批量入市。

**值得关注的原因：** 编程是 Agent 最早规模化兑现价值的生产力场景，也是模型能力差异最透明的竞技场；"AI 工具替代初级程序员"从趋势变为招聘现实，倒逼人才结构转型。

**值得关注的原因：** 教育、防灾等公共品场景是 AI 价值"温度"的试金石，也是中国 AI 出海（尤其"一带一路"国家）最易建立信任的切入点。

### 17. 优必选 U1 情感陪伴机器人翻车，消费级落地痛点暴露

### 18. 星炽动力（海尔系）全面量产，正奇未来（前华为百度高管）数亿元融资

**值得关注的原因：** 给"量产元年"叙事泼了冷水也点了要害：本体的工程化只是上半场，操作模型的泛化能力才是决定具身智能能否真正进产线的"下半场"。投资与选型应更关注"数据—模型—泛化"飞轮而非单体演示。
