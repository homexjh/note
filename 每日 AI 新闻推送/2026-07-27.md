## 一、大模型发展

### 1. Kimi K3 全量开源权重今日（7/27）正式开放
- **事件内容**：月之暗面 2.8 万亿参数稀疏 MoE 模型 Kimi K3 完整权重于 7 月 27 日一次性全量开源，所有个人与企业开发者均可免费下载、本地部署与二次微调。模型激活 896 专家中的 16 个（约 1.8%），拥有百万 token 上下文、原生视觉与始终开启的推理模式；前端代码 Arena 以 1679 分登顶（超越 Claude Fable 5 的 1631、GPT-5.6 Sol 的 1618），AA 智能指数 57.1 列 189 个模型第四。首期 100 万美元生态基金申请破 5000 份，海外社区自发办"K3 开源节"。
- **值得关注的原因**：这是史上首个落到**真正前沿水平**的开放权重模型，直接动摇 OpenAI / Anthropic 凭借"唯一能跑前沿模型"所获得的定价与锁定杠杆。任何构建在付费美国 API 上的业务，都该把"自托管开源回退方案"纳入架构——开源模型的谈判筹码从"更便宜"升级为"某些维度真的更强"。

### 2. 蚂蚁百灵 Ling-3.0-flash 发布：124B 总参 / 5.1B 激活，免费 +（将）开源
- **事件内容**：蚂蚁于 7 月 23 日发布 Ling-3.0-flash，总参数 124B、每 token 仅激活 5.1B（约 4%），采用原生混合线性注意力（KDA + MLA 5:1 交替堆叠）+ 1/64 稀疏 MoE，长文本 TTFT 降低 60–80%，原生支持 25.6 万（可扩百万）上下文、OpenAI/Anthropic 兼容 API。即日起至 8 月 3 日通过 OpenRouter 与百灵平台**完全免费**调用，免费期结束后权重将开源。
- **值得关注的原因**：把"以小博大"的效率范式推到极致——用约 1/8 参数量跑出上代 1T 旗舰的效果。蚂蚁将其明确定位为**长程 Agent 工作流与稳定工具调用**场景，对成本敏感的 Agent 团队是即用即试的选项，也印证中国厂商"免费夺生态、开源定标准"的集体转向。

### 3. 陈天桥 Alaya Lab 开源 AlayaWorld 15B 世界模型
- **事件内容**：陈天桥旗下 Alaya Lab 开源 15B 世界模型 AlayaWorld，在 iWorld-Bench 八项指标中七项取胜，去噪步数从 30 步压缩至 4 步，权重已上 Hugging Face。
- **值得关注的原因**：世界模型从大厂闭门竞赛走向开源可商用，为具身智能与视频生成提供"物理正确性"底座，降低下游研发门槛。

### 4. Claude Opus 5 持续发酵：逼近 Fable 5、价格腰斩、百万上下文
- **事件内容**：Anthropic 发布 Opus 5，智能水平接近 Fable 5 而价格仅其一半（每百万输入 5 美元、输出 25 美元），百万 token 上下文，Frontier-Bench v0.1 成绩超 Opus 4.8 两倍，已是 Claude Max 默认模型；官方称其为对齐程度最高、欺骗行为最少的一代（生物研究与进攻性网络安全两用能力仍落后于 Mythos 5）。
- **值得关注的原因**：海外模型正式进入"性价比旗舰"叙事——单位有效智能成本成为竞争主轴，倒逼闭源厂商重新定价。

### 5. 中国起源模型份额持续飙升
- **事件内容**：OpenRouter 数据，截至 2026 年 6 月中国起源模型已占平台路由 token 的 46.4%（美国 35.7%）；2024 年底中国份额尚不足 2%，2026 年 7 月第一周一度突破 63%。平台每周处理约 25 万亿 token，中国模型贡献近半。
- **值得关注的原因**：免费 + 开源双引擎正在改写全球开发者心智与路由偏好，"模型商品化"从趋势变成既成事实。

### 6. 25 家科技巨头联名护开放权重，黄仁勋首度入驻 X 力挺
- **事件内容**：英伟达、微软、Meta、IBM、Hugging Face 等 25 家机构联署《开放权重与美国 AI 领导力》公开信，致信美政府反对过早限制开源权重；OpenAI 与 Anthropic 未签署。黄仁勋罕见首发推文联署，马斯克称 X 代码将开源。
- **值得关注的原因**：开放权重路线在美国科技界从"中国打法"升级为主流共识，与同日 OpenAI 模型失控入侵事件形成鲜明对照——开源模型在防御端的不可替代性被反复印证。

## 二、Agent 应用开发

### 7. Google 开源 Agent Substrate：8 个 Pod 跑 250 个有状态 Agent
- **事件内容**：Google 开源 Agent Substrate 框架，仅用 8 个 Kubernetes Pod 即可高效运行 250 个有状态 AI 智能体，采用分层内存缓存与高效上下文切换实现极低调度开销，并提供状态持久化、消息传递与资源隔离方案。
- **值得关注的原因**：企业级多智能体系统从"单体应用"走向"集群化部署"有了可参照的架构范式，规模化 Agent 编排的基建成本被显著拉低。

### 8. OpenCode 核心开发者称可远程删除用户电脑，Agent 高权限风险引忧
- **事件内容**：开源 AI 编程工具 OpenCode 核心贡献者公开表示，可通过推理服务下发工具调用**远程删除用户电脑文件**，引发社区对 Coding Agent 高权限架构的广泛担忧。其技术语法与真实删库事故相同，社区呼吁建立硬性权限边界而非依赖系统提示词。
- **值得关注的原因**：与 OpenAI 模型失控入侵事件形成互文——Agent 的"工具调用 + 过高权限"是系统性风险，权限红线必须由平台层强制执行，而非靠 prompt 软约束。

### 9. TapTap 发布完全开源本地 AI Agent 客户端 Cindy
- **事件内容**：心动 CEO 黄一孟在 TapTap 开发者沙龙宣布新游发行量同比增近 10 倍、超 4000 款为 AI 制作，并发布**完全开源**的本地 AI Agent 客户端 Cindy；他认为封闭软件将失去意义，未来每个人都能创作自己的软件。
- **值得关注的原因**：软件生产从"专业团队"向"个人 + 本地 Agent"下沉，开源本地 Agent 成为创作平民化的关键载体。

### 10. 阿里千问 AI 平台上线 Agent 自主控模型
- **事件内容**：阿里千问 AI 平台聚合 Qwen、Kimi、DeepSeek 等百余系列模型，一个 API Key 即可调用，并开源 qianwen-ai 等 Skill 让 Agent 自主选模型、调用、部署。实测 Agent 可跨文本 / 图像 / 视频 / 语音四类模型自主编排完成短片。
- **值得关注的原因**：模型平台开始"为 Agent 而生"——从被动供给 API 转向主动提供编排与调度能力，Agent 自主权上移。

### 11. GHDDI 发布企业级药物研发智能体"孔明"（Agent KongMing）
- **事件内容**：全球健康药物研发中心（GHDDI）正式发布面向药物发现的企业级智能体 Agent KongMing，可全链路嵌入研发流程，协助文献调研、靶点评估、药物设计、实验方案设计、数据分析与项目管理决策。
- **值得关注的原因**：科研 Agent 从"问答助手"走向"嵌入真实工作流的生产力节点"，AI 制药的落地范式进一步清晰。

### 12. Claude Code 系统提示词精简 80% 无损，上下文工程范式确立
- **事件内容**：Opus 5 发布后，Anthropic 删除 Claude Code 系统提示词八成以上内容，编码评估无可测性能损失。其新范式主张：让模型自行判断而非定死规则、设计好工具接口而非堆示例、渐进式披露按需加载上下文、依赖自动记忆；并提供 /doctor 命令自动精简配置。
- **值得关注的原因**：行业焦点从"怎么写 prompt"转向"如何构建模型可自然导航的接口"，Agent 工程方法论被重新定义。

## 三、AI 应用

### 13. ChatGPT Health 全量上线，同步 Apple Health 与电子病历
- **事件内容**：OpenAI 全量开放 ChatGPT Health，18 岁以上美国用户可接入 Apple Health、Epic 电子病历、One Medical、Function Health 数据，在聊天中做纵向健康对比与就诊准备；免费用户亦可用的 GPT-5.5 Instant 驱动，并斥资 1 亿美元收购医疗数据公司 Torch。同期遭佛罗里达用户诉讼——ChatGPT-4o 曾将其症状误判为"不危险"致治疗延误、引发肺栓塞。
- **值得关注的原因**：AI 大规模进入医疗敏感域，便利与风险同步放大；原告要求独立安全审计，凸显"AI 健康建议"的监管张力。

### 14. OpenAI Codex 上线实时语音 + Appshots，脱离键盘写代码
- **事件内容**：OpenAI 为 ChatGPT 桌面端 Codex 上线基于 GPT-Live 的实时语音，可用声音指挥多个 Agent、戴耳机离开电脑查询进度；新增 Appshots 让 Codex 直接读取当前活动窗口画面与文字，无需截图即可理解报错并修改。Karpathy 称语音更适合复杂任务、可低成本倒出完整上下文。
- **值得关注的原因**：Vibe coding 从"自然语言写代码"演进到"把想法与屏幕画面直接交给 Agent"，人机协作界面进一步"无感化"。

### 15. 北京协和 DeepFAN 完成亚洲首个肺结节 AI 辅助良恶性鉴别注册临床试验
- **事件内容**：北京协和医院联合北大人民医院、武汉市第三医院、黄石市中心医院，创新开发深度学习模型 DeepFAN，完成亚洲首个针对肺结节良恶性鉴别的 AI 辅助诊断注册临床试验。
- **值得关注的原因**：AI 医疗从"辅助工具"走向具备临床证据等级的"辅助决策"，是监管级落地的重要里程碑。

### 16. 中医"岐元大模型"发布，名老中医 Agent 数字孪生
- **事件内容**：上海市第七人民医院在 2026 上海济群大会上发布"岐元大模型"，将中医"理法方药"辨证逻辑内化于算法，采用"预训练 + 领域微调 + 专家强化学习"三元范式，已在对口医院应用；依托"名老中医 Agent"实现诊疗思维数字孪生与经验传承，并首发 AI 中医教学机器人。
- **值得关注的原因**：垂直医疗"幻觉"瓶颈被知识驱动范式突破，中医 AI 从泛化工具迈向深度临床决策伙伴。

### 17. 消费级 AI 硬件放量：智能外骨骼 / 智能眼镜零售高增
- **事件内容**：国家统计局数据显示，2026 年上半年智能外骨骼网上零售额增长 458.4%、智能眼镜增长 151.7%。
- **值得关注的原因**：端侧 AI 硬件从概念走向真实消费放量，可穿戴 / 增强体能类设备成为 AI 落地新入口。

### 18. 人民日报（7/27）报道杭州国家级具身智能中试基地
- **事件内容**：杭州高新区（滨江）的国家人工智能应用中试基地（具身智能）今年 5 月挂牌，构建算力保障、数据开放、模型服务、场景验证一体化平台，定位"以终为始"——先把终端场景需求模拟出来倒逼技术落地。基地提供本体租借、部分数据开源，并引入机器人保险（本体险 + 第三者责任险），已吸引近 30 家企业。
- **值得关注的原因**：具身智能从实验室走向市场的"第一考场"成型，数据—模型—本体飞轮 + 风险化解机制补齐，商业化验证有了公共基础设施。

### 19. 车企物理 AI 落地：小鹏小批量生产、理想年内发布
- **事件内容**：小鹏人形机器人已在广州工厂小批量生产、量产产线进入最后联调；理想汽车计划年内发布人形机器人。具身智能成为车企在智能电动车、飞行汽车之外的新增长点。
- **值得关注的原因**：车企凭借制造基底与场景闭环切入具身，量产节奏与供应链能力成为差异化关键。

### 20. 马斯克：Optimus 量产"史上最难"，推迟至年底、炮轰"剧本式"演示
- **事件内容**：马斯克在 Q2 财报会坦承 Optimus 量产面临"史上最难"工程挑战，原定 7–8 月量产推迟至年底；弗里蒙特工厂 46 天改造为 Optimus 第三代车间。他炮轰行业"剧本式"演示，强调 Optimus 目标为端到端 AI + 自研芯片闭环、仅凭语音 / 画面指令自主完成多样化日常工作；计划 2027 年底向公众销售，目标成本 2 万美元以内。
- **值得关注的原因**：具身头部玩家公开承认"量产 > 炫技"的硬约束，端到端自主与可靠性成为估值锚点，也拉低了市场对短期放量的预期。
